# GameZone 

## About the Project
GameZone is a gaming company website designed for gamers to explore games, discover new releases, and learn about gaming products.

## Features
- Gaming homepage with hero section
- Featured games and gaming categories
- Latest releases
- About and contact sections
- Responsive design
- Search, sorting, and filtering
- Local storage for data persistence

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## Installation
1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
